# Neudact Engineers — Tender Management, Procurement Support & Custom Software

An intentionally designed, editorial website positioning **Neudact Engineers** (led by **Shailinya Saxena**) across two core business pillars:
1. **Tender Management & Procurement Support**: Structured tender research, document & clause analysis (NITs/RFPs), pre-qualification (PQ) eligibility matrices, compliance documentation, pre-bid query support, and pipeline tracking across GeM, IREPS, CPPP, and state procurement portals.
2. **Software Development & Automation**: Custom web applications, single-screen operational dashboards, automated Telegram alert bots, Google Sheets API integrations, and tender document parsing utilities.

Designed with an editorial, tactile aesthetic built around warm ivory paper tones (`#FBF9F5`), restrained hairline rules, deep charcoal typography, and terracotta accents.

---

## 🏛️ Core Business Pillars

### Business 1: Tender Management & Procurement Support
- **Tender Identification & Research**: Filtering by industry, geography, contract value, and business capabilities.
- **Tender Document Analysis**: Clause-by-clause review of NITs, RFPs, technical specifications, payment schedules, and liquidated damages.
- **Eligibility & Qualification Assessment**: Detailed PQ matrix analysis covering technical eligibility, turnover, solvency, and similar work criteria.
- **Bid Documentation & Compliance**: Preparation of clause-by-clause compliance statements and Cover 1 / Cover 2 checklists.
- **Pre-Bid Query Support**: Identification of tender ambiguities and drafting of formal pre-bid clarification requests.
- **Tender Tracking & Reporting**: Pipeline monitoring, EMD/PBG tracking, corrigenda surveillance, and deadline countdowns.
- **Procurement Research**: Opportunity intelligence and benchmark studies for contracting firms.

### Business 2: Software Development & Automation
- **Custom Web Applications & Portals**: Fast, modular full-stack applications in React 19 and Node.js.
- **Operational Dashboards & Milestone Trackers**: Real-time project status and deadline surveillance tools.
- **Workflow & Bot Automation**: Asynchronous Telegram bots and WhatsApp webhook alerts for field-to-office communication.
- **Automated Document Processing**: Specialized Python tools to parse 80+ page tender PDFs into formatted Excel matrices.

## 🏭 Industries & Sectors Served

- **Railways & Railway Infrastructure**: Works under IREPS, RailTel, zonal signaling, track-side electrical, and telecommunication.
- **Telecom & OFC Networks**: Fiber laying, HDD/trenching, ducting, tower construction, and maintenance (BSNL, BharatNet).
- **Solar EPC & Renewable Energy**: Rooftop solar, MW-scale ground-mounted EPC, inverter/BOS supply, and PSU clean energy bids.
- **CCTV, Surveillance & Safe City**: Municipal surveillance, ICCC smart city command centers, ANPR, and campus security tenders.
- **Government & PSU Procurement**: Technical equipment, hardware supply, rate contracts, and annual maintenance tenders on GeM.
- **Infrastructure & EPC Contracting**: Civil works, sub-station electrical EPC, pipeline infrastructure, and turnkey government works.

## 🛠️ Local Development & Build

```bash
# Install dependencies
npm install

# Start local development server with Hot Module Replacement
npm run dev

# Run production build
npm run build

# Preview production build locally
npm run preview
```
